엔터프라이즈 보안을 고려한 지식기반 AI 업무 에이전트 구축

사내 규정과 업무 문서, 과거 보안성검토 이력을 찾아 검토 초안 작성에 활용하는 AI 에이전트를 구축했습니다. Copilot Studio로 사내 시스템을 연결하고, 여러 문서를 조회하는 워크플로와 Python 기반 문서 수집 프로그램을 직접 구현했습니다. 자료의 출처를 확인하고 민감정보 취급을 최소화하며, 최종 판단은 담당자가 내리도록 업무 흐름을 설계했습니다.

  • AI Security
  • Knowledge-based Agent
  • Security Review Automation
  • Enterprise Integration
구현 내용과 보안 설계

시작한 이유와 맡은 일

보안성검토를 할 때마다 사내 기준, 시스템 운영 문서, 과거 검토의견을 여러 시스템에서 찾아 비교해야 했습니다. 이 과정을 줄이고 기존 검토 경험을 다시 활용할 수 있도록, 자료 검색부터 검토 초안 작성까지 이어지는 에이전트를 만들었습니다.

업무 요구사항과 에이전트 지침을 정리하고, 보안 설계, 시스템 연동, 데이터 수집 자동화, 기능 검증과 문서화까지 직접 수행했습니다.

직접 구현한 내용

사내 Confluence 연동과 다중 문서 조회
온프레미스 데이터 게이트웨이와 사용자 지정 커넥터로 사내망의 Confluence를 Copilot Studio에 연결했습니다. REST API를 이용한 문서 검색과 본문 조회를 별도 도구로 구성하고, Power Automate에서 여러 문서를 순차 조회한 결과를 모아 에이전트에 반환하도록 구현했습니다.
사내 기준과 과거 검토 이력 연결
SharePoint의 규정·지침·매뉴얼과 과거 보안성검토 이력을 지식 소스로 구성했습니다. 검토 목적, 시스템 구조, 처리 데이터, 위험과 조치사항을 기준으로 유사 사례를 찾도록 했습니다. 현재 요청자료와 현행 기준을 우선하고, 과거 승인이나 예외는 참고자료로 구분했습니다. 법적 근거 확인을 보조하는 법령 조회 MCP도 연결했습니다.
그룹웨어 문서 수집 자동화
Python과 Playwright로 그룹웨어 상세 화면의 본문과 문서 식별정보를 수집하는 프로그램을 개발했습니다. 중복 수집 방지, 실패 재처리, 중단 후 재실행, 파일 무결성 확인을 구현·검증했습니다. 수집한 자료는 검색용 텍스트로 변환한 뒤 담당자가 문서 저장소에 반영하도록 했으며, 수집 성공·업로드 완료·에이전트 검색 가능 여부를 각각 확인하도록 절차를 정리했습니다.

보안성검토에 적용한 흐름

  1. 요청서 분석
  2. 추가 확인사항과 인터뷰 질문 도출
  3. 답변과 증빙 반영
  4. 사내 기준 및 유사 사례 비교
  5. 검토의견 초안 작성
  6. 담당자 검토

검토 대상의 기능, 데이터 흐름, 인증·권한, 외부 연동, 개인정보 처리 쟁점을 정리하도록 구성했습니다. 초안에는 확인된 사실과 추가 확인사항, 필수 조치와 권고사항을 구분해 작성하도록 했습니다.

보안과 검토 품질을 위해 정한 기준

  • 자료 범위와 근거 확인. 정보원별 활용 목적을 정하고 조회 중심으로 도구를 구성했습니다. 검색 결과에 문서가 있다는 것과 본문을 실제로 확인한 것을 구분하고, 확보한 내용과 출처에 근거해 답변하도록 했습니다.
  • 자료의 시점과 효력 구분. 현행 지침, 과거 사례, 협의 기록을 구분해 과거 승인이나 계획을 현재의 승인·완료 상태로 해석하지 않도록 했습니다.
  • 민감정보 취급 최소화. 개인정보와 인증정보의 불필요한 입력·출력을 줄이고, 수집 프로그램의 인증정보와 로그 취급 기준을 정리했습니다.
  • 문서 안의 지시 처리. 검색 문서나 도구 응답에 담긴 지침 변경, 비밀 전송, 접근 우회 요구를 실행 지시로 받아들이지 않도록 에이전트 지침을 작성했습니다.
  • 담당자의 최종 판단. AI의 역할은 검색·분석·초안 작성까지로 정하고, 최종 승인·위험수용·법률적 판단은 담당자가 수행하도록 구분했습니다.

이 중 에이전트 운영 지침은 기술적 접근제어와 구분됩니다. 문서 내 지시에 대한 처리 기준을 마련한 것이며, 프롬프트 인젝션을 완전히 차단한다는 의미는 아닙니다.

결과

협업 문서의 API 조회와 문서 저장소 검색을 연결하고, 여러 자료를 비교해 검토 초안을 작성할 수 있는 흐름을 구현했습니다. 그룹웨어의 기존 기록을 다시 수집하고 신규 자료를 반영하는 절차도 마련했습니다.

어떤 자료를 근거로 삼았는지, 아직 확인하지 못한 내용은 무엇인지 드러나도록 구성했습니다. 업무에 필요한 자동화를 구현하면서 자료 활용 범위와 담당자의 판단이 필요한 지점을 함께 정리한 경험입니다.
